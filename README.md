# Faturas Backup e Envio 🧾📱

Aplicação Android moderna desenvolvida em **Jetpack Compose** e **Kotlin** para digitalizar, organizar, gerir e partilhar faturas de forma rápida, segura e totalmente estruturada ao gosto do utilizador.

---

## 🚀 Funcionalidades Principais

- **📸 Digitalização Inteligente:**
  - Integração com o Google ML Kit Document Scanner para digitalização automática de documentos e faturas através da câmara.
  - Suporte para importação de imagens diretamente da galeria.

- **📁 Explorador e Organização Personalizada:**
  - Organização flexível por **Dia**, **Mês**, **Ano** ou **Pastas Personalizadas**.
  - **Criação de Pastas:** Crie novas pastas com o nome que desejar. As pastas aparecem imediatamente no explorador, mesmo vazias.
  - **Mover Ficheiros:** Transfira facilmente faturas entre diferentes pastas, dias, meses ou anos.
  - **Gestão Segura:** Elimine faturas ou pastas indesejadas de forma simples (operação contida estritamente no armazenamento isolado da aplicação).

- **📤 Partilha Avançada:**
  - Seleção múltipla de faturas.
  - Partilha rápida em formato de imagem individual (**JPEG**) ou compactadas num único ficheiro **ZIP**.
  - Configuração de assunto e corpo de email com suporte para tags dinâmicas (ex: `%DATE%`).

- **⚙️ Armazenamento Flexível:**
  - Armazenamento predefinido na pasta da aplicação ou suporte para diretório personalizado via *Storage Access Framework* (SAF).

## 🛠️ Tecnologias Utilizadas

- **Kotlin** & **Jetpack Compose** (Material 3)
- **Google ML Kit Document Scanner**
- **AndroidX (Core, Lifecycle, Navigation Compose)**
- **Coil** (Carregamento de imagens)
- **DataStore Preferences** (Gestão de definições)

---

## 📦 Instalação e Utilização

1. Descarregue o ficheiro `.apk` da versão release.
2. Instale no seu dispositivo Android (Android 8.0 / API 26 ou superior).
3. Comece a digitalizar, organizar e partilhar as suas faturas!
